⚙️ Weltrade MT5 Connection Setup

Connect the web scanner to your live Weltrade MetaTrader 5 terminal for real-time SyntX, FXvol, Volatility, Crash/Boom, PainX, GainX, Regime, Indices, Forex, Metals, and Crypto data.

📊 Connection Status

🔐 Weltrade MT5 Credentials

These credentials are stored locally in ~/.weltrade-credentials.json and used only to connect to your local MT5 terminal. They never leave your machine.

🛠 Step-by-Step Installation

1. Install Python + MetaTrader5 package

# Windows / macOS / Linux
pip install MetaTrader5 flask flask-cors pandas numpy

# (Linux users also need to install Wine, since MT5 is Windows-only)
# Ubuntu example:
sudo apt-get install -y wine64

2. Install the Weltrade MT5 Terminal

Download the official Weltrade MT5 installer from:
https://weltrade.com/platforms/metatrader5

During install, log into your Weltrade account. Make sure
all your desired symbols (SyntX, FXvol, Volatility, Crash/Boom,
PainX, GainX, US30, NAS100, EURUSD, XAUUSD, etc.) are visible
in Market Watch (right-click → Show All).

3. Start the Python Bridge

# From the project root:
python weltrade_mt5_bridge.py

# (It listens on http://localhost:5555)

4. Connect the Web Scanner

Click Connect to MT5 above and enter your Weltrade credentials.
The scanner will automatically pull real OHLCV data from your MT5.

If you prefer, use the standalone MQL5 EA below - it runs natively
inside MT5 and is even faster (no HTTP round-trip):

Install: copy the .mq5 file to MQL5/Experts/ inside your MT5 data folder, then drag it onto any chart. Press S on the chart to trigger a manual scan.

❓ Troubleshooting

"Initialize failed" / "MT5 initialization error"

Weltrade MT5 must be installed in its default location, or you must supply the full path in the form above. Open MT5 at least once and log into your account so credentials are cached.

"Login failed: invalid account"

Verify the server name matches your account. Most Weltrade accounts use Weltrade-Live or Weltrade-Demo. Open MT5 → File → Login to confirm.

"Symbol not found" / missing volatility indices

Open MT5 → right-click Market Watch → "Show All". Different Weltrade account types (Standard, Pro, SyntX) carry different symbols.

Bridge can't connect to Python

Make sure weltrade_mt5_bridge.py is running. The Node server auto-spawns it on startup, but you can run it manually for easier debugging.
